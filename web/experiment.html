    Plays the best δ's segments as the prefix grows: from start to end in steps equal steps, both ends included; start and end can be expressions in n, like n/3, 3n/4 or n-100, rounded to a whole number (empty: start = end = n/2, steps 1, so the one prefix t = n/2; start = end is always a single prefix, and t = 0, the empty prefix, is skipped), with the run's seed and permutation. Each prefix tries δ = 0.5, 1, 1.5, … until no larger δ can lower qc = log₂δ + log₂λ.

    Keys against rank, each segment's line with its ±δ band, keys over 1..n so the prefix fills in. Click a row to draw that δ (pauses). Keys: ← → step through the prefixes, ↑ ↓ move through the δs. Drag across the plot to zoom in on a range of keys, double-click to zoom out.
